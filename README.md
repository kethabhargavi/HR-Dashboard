# 📊 HR Analytics Dashboard using Microsoft Excel

## Project Overview

Organizations generate a significant amount of employee data every day. HR teams often struggle to transform this raw data into meaningful insights that support strategic workforce planning and business decision-making.

This project demonstrates how Microsoft Excel can be used to build an interactive HR Analytics Dashboard that provides a centralized view of employee demographics, salary distribution, workforce allocation, leave trends, and performance metrics.

The dashboard enables HR managers and business leaders to monitor key workforce indicators, identify trends, and make informed decisions without manually analyzing thousands of records.

---

# Business Problem

Human Resource departments are responsible for managing employees, tracking workforce performance, monitoring salaries, and analyzing employee demographics.

However, HR data is usually stored in spreadsheets containing hundreds or thousands of rows, making it difficult to answer important business questions such as:

- How many employees are currently working in the organization?
- Which department has the largest workforce?
- What is the gender distribution?
- Which age group has the highest number of employees?
- Which job role takes the most leave?
- How are employees distributed across different work locations?
- Which job role contributes the highest salary expense?
- What percentage of employees work remotely?
- How are contract employees distributed compared to full-time employees?

Without an interactive dashboard, answering these questions requires manually filtering, sorting, and analyzing large datasets, which is time-consuming and prone to errors.

---

# Solution

This project solves the above problems by creating an interactive HR Analytics Dashboard in Microsoft Excel.

The dashboard automatically summarizes workforce data into meaningful visualizations and allows users to interact with the report using slicers.

Users can instantly filter the dashboard by:

- Department
- Gender

The dashboard dynamically updates all charts, KPIs, and visualizations, providing real-time insights into workforce performance.
